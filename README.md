# Akshunn Garg — Portfolio

A responsive, single-page personal portfolio built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Deploy quickly with Vercel
1. Create a GitHub repository and upload `index.html`.
2. Go to https://vercel.com and import the repository.
3. Deploy using the default settings (static site).

## Before publishing
- Add your real LinkedIn and GitHub URLs if you want them displayed.
- Add live demo / source-code links to the project cards when available.
- Confirm resume facts and metrics are still current.
